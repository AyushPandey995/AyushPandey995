## 🚀 Featured Projects

### 🌐 SocialSphere

**Social Network Data Analysis & Recommendation System using Pure Python**

Analyzes social network data to identify relationships and interaction patterns while implementing a recommendation system based on the analyzed data.

### 📊 InstaData Insights

**Instagram Data Cleaning & Analysis using Pure Python**

Cleans, structures, and analyzes manually collected Instagram data to identify insights such as highest followers, highest number of posts, and other key metrics.

### 📚 BookInsight

**Book Data Extraction using Web Scraping**

Extracts book name, author, rating, and price from web pages and organizes the collected information into a structured dataset.

### 💬 QuoteMiner

**Quotes Web Scraping & Data Extraction**

Scrapes quotes and author information from websites and converts the extracted data into a structured format.

### 🤖 CourseAssist AI

**RAG-Based AI Course Assistant**

A RAG-based application that uses **embeddings and semantic search** to identify the relevant course, lecture, and timestamp where a requested topic is taught.

### 🏠 HousePrice ML

**California Housing Price Prediction**

Uses **Python, NumPy, Pandas, Matplotlib, and Scikit-learn** to preprocess housing data, analyze features, and build a regression model for price prediction.
